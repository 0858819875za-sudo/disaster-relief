## F5 — จัดสรรและตัดจ่าย

ต้องรัน `docs/sql/17_f5_hardening.sql` และ `docs/sql/18_f5_features.sql` ใน Supabase ก่อนทดสอบ

### เตรียมข้อมูลและลำดับการเก็บหลักฐาน

1. รัน `docs/sql/22_tc_f5_setup.sql` — ได้คำขอ `[TEST] TC ข้าวสาร 5 กก.` 50 ถุง (ศูนย์พักพิงวัดคลองแห)
   และล็อต A 100 / ล็อต B 20 / ล็อต C หมดอายุ 40 (ศูนย์รับบริจาคหาดใหญ่)
2. ทำตามลำดับนี้ เพราะแต่ละเคสต่อยอดจากเคสก่อน (ล็อกอินเป็น admin ทั้งหมด)
   - **TC09** เปิดคำขอในหน้าจัดสรร → ล็อต C ต้องไม่อยู่ในตัวเลือก
   - **TC08** ใส่ 50 ในล็อต B (เหลือ 20) → ปุ่มยืนยันกดไม่ได้ ยอดไม่เปลี่ยน
   - **TC07** จ่าย 30 จากล็อต A → ล็อต A เหลือ 70, คำขอ `partial`
   - **TC11** ยกเลิกรายการ 30 นั้นในหน้าประวัติ (กรอกเหตุผล) → ล็อต A กลับเป็น 100, คำขอ `pending`
   - **TC10** จ่าย 30 จากล็อต A อีกครั้ง แล้วจ่ายส่วนที่เหลือ 20 → คำขอ `fulfilled`
3. เก็บหลักฐานเสร็จแล้ว ยกเลิกรายการจัดสรรที่ค้าง (ถ้ามี) แล้วรัน `docs/sql/20_cleanup_test_records.sql`

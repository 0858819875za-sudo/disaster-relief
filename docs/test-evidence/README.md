### ฟีเจอร์เพิ่มของ F5

| สิ่งที่ทดสอบ | ขั้นตอน | ผลที่คาดหวัง |
|---|---|---|
| จับคู่อัตโนมัติ (FEFO) | เลือกคำขอที่มีหลายล็อต | ล็อตใกล้หมดอายุอยู่บนสุด และจำนวนถูกเติมไล่จากล็อตแรกจนครบที่ขาด |
